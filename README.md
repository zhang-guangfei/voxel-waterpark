# 碧湾水上乐园 · V5.5 水上动感版

一款采用独立 WebGL2 引擎的 3D 体素海滨水上乐园游戏。内置原创夏日 BGM，无外部运行依赖。

## 游玩

直接在支持 WebGL2 的现代浏览器中打开 `index.html`，或通过 GitHub Pages 在线游玩。浏览器通常需要玩家首次互动才会允许音乐播放。

- WASD：步行、上下楼梯、游泳。
- Shift：奔跑；空格：跳跃，在池边可攀爬上岸。
- 鼠标拖动：观察；滚轮：第三人称镜头距离。
- V：切换第一/第三人称；F：第一人称；C：第三人称。
- E：设施交互、滑行、泳圈、上岸；G：可选导航；Esc：取消导航。
- 支持移动端屏幕控制、三档画质、经营模拟及本地存档导入导出。

## V5.5 更新

- 下水动作：跨上池沿、落水、进入游泳状态。
- 上岸动作：靠近池沿，撑起身体并攀爬回地面。
- 滑行按坡度和阻力计算速度，增加冲刺、速度线、动态视野、风声及水花。
- 高速滑行结束后进入落水缓冲，随后由玩家自行游泳上岸。
- 保留 26 条基础滑道、1 条可扩建滑道、45 米塔、造浪池、漂流河、动态游客、昼夜变化及经营模式。

## GitHub Pages 部署

1. 创建 `voxel-waterpark` 仓库（如使用 GitHub Free，请选择 Public）。
2. 将 `index.html`、`README.md` 和 `.nojekyll` 提交到仓库 `main` 分支根目录。
3. 在 Settings → Pages → Build and deployment 中选择 Deploy from a branch，分支选择 `main`，目录选择 `/(root)`，保存。
4. 部署成功后访问 `https://<GitHub用户名>.github.io/voxel-waterpark/`。后续将新版 HTML 覆盖 `index.html` 并提交即可更新网站。

无需 npm、编译或额外服务器。`.nojekyll` 用于跳过 Jekyll 构建。

## 测试与限制

V5.5 已通过 JavaScript 语法检查及 Chromium 模拟图形接口下的楼梯、27 条滑道（含扩建）、泳池和漂流河出入水逻辑测试。尚未在真实浏览器 GPU 环境中确认最终帧率与所有视觉效果。游戏采用简化的运动、碰撞及水体模型，不是现实设施的工程模拟。浏览器本地文件与 GitHub Pages 属于不同存储来源，原有存档请通过游戏的导出、导入功能迁移。
